# Recursos Mixe

Recursos tipográficos desarrollados para apoyar la representación escrita de las lenguas mixe-zoques y la exploración de la escritura epiolmeca.

## Familias tipográficas

- **Ayuujk:** familia serif diseñada para composición de textos.
- **Mutsk:** familia tipográfica orientada a primeros lectores.
- **Tuki:** familia sans serif humanista (incluye glifos silábicos del epiolmeca).
- **Tuki Glifos:** fuentes para la representación de signos de la escritura epiolmeca.
